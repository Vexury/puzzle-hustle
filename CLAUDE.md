# Puzzle Hustle
Web-first puzzle app (React 19 + React Compiler, Vite 8, TypeScript 7, pnpm workspace), packaged with Capacitor 8 for Android and iOS. Context, decisions and open items: ~/hub/wiki/puzzle-hustle.md (read it first).

- Puzzle logic lives in `packages/core` and stays DOM-free; UI in `apps/web`. Nine types: shapes, nonogram, mosaic, crowns, stars (one `regions` module), sudoku, killer (one `sudoku` module), kakuro, zip. Kakuro and zip ship easy/medium only; their hard/genius generators are untuned, so `PERIOD_TYPES` in schedule.ts keeps them out of the weekly/monthly rotation.
- Adding a type: core module with generator, solver (uniqueness), hint, difficulty score and canonical key, plus tests; then an adapter in `packages/core/src/registry.ts`, entries in `PUZZLE_TYPES`/`PUZZLE_META` (types.ts), exports in index.ts, a game component under `apps/web/src/<type>/` with the shared props (spec, onMove, onSolved, onHintUsed, requestHint, locked, initialState, onStateChange, optional viewKey), a branch in `pages/Play.tsx`, an icon in `components/PuzzleIcon.tsx`, how-to text in `lib/howto.ts`, a check in `test/levels.test.ts`, then `pnpm levels <n> <type> [easy,medium]` in packages/core (optional difficulty list).
- Level packs: `packages/core/src/levels.json`, generated by `pnpm levels <count> [type]` in append mode (existing levels keep their numbers while the type's `*_VERSION` is unchanged). Changing a generator or solver changes seeds and scores: bump the version, regenerate, run tests.
- Daily/weekly/monthly seeds derive from the Europe/Berlin date (`schedule.ts`) and take the first seed the type's adapter accepts. Deterministic budgets only, so every device agrees.
- Progress, in-progress boards, zoom/scroll views and settings live in localStorage (`apps/web/src/lib/storage.ts`, keys `ph:*`). No backend.
- Theme tokens mirror vexury.dev (`apps/web/src/theme.css`); every change must work in light and dark (`[data-theme]`). Big grids use `lib/useZoomViewport.ts` (pinch, two-finger pan, Ctrl+wheel).
- Hints go through `HintProvider` (`lib/hints.ts`): free on web, ads and a one-time purchase later in native builds.
- Verify: `pnpm test`, `pnpm -r typecheck`, and a browser check with `pnpm dev`. CI runs tests before deploying; Vitest timeout is 60 s because GitHub runners are slow.
- Remotes: `origin` is the NAS bare repo, `github` is the public deploy repo (GitHub Pages at vexury.dev/puzzle-hustle). Push both. While subagents work in the tree, stage files explicitly instead of `git add -A`.
- Reference screenshots in `docs/reference/` are gitignored (third-party app).
