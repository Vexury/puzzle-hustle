> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Slabs (dominoes with region rules, after NYT Pips) as the tenth puzzle type, with levels in four difficulties and a daily on medium.

**Architecture:** A new `packages/core/src/slabs/` module: `solver.ts` holds the model, a tiered propagator over slab placements and cell values (doubling as uniqueness proof and difficulty rating), an exact counter and the keys; `puzzle.ts` holds presets, a tiling-first generator that strengthens then weakens rules, and pure player-state and hint functions. ## Review Focus

1. A fast flick must never be read as a drag that moves the slab, and a slow short drag must never rotate it. Pinned in Task 4 by `classifyGesture` tests.
2. Dropping a slab so it covers another must return exactly the covered slab(s) to the tray and leave no overlap. Pinned in Task 3 (`slabsPlace`).
3. Rotating or flicking near blocked cells and the board edge must skip invalid orientations and never put a half outside the playable area. Pinned in Task 3 (`slabsRotate`, `slabsOrient`).
4. A saved state that does not fit the spec (wrong length, overlap, blocked or off-board cell, bad direction) loads as an empty tray. Pinned in Task 3 (`validSlabsState`).
5. Pressing hint repeatedly from any board, including slabs sitting on each other's solution cells, reaches the solved board. Pinned in Task 3.

## Model

- Directions: `0 = E, 1 = S, 2 = W, 3 = N`, clockwise on screen. `SLAB_DR = [0, 1, 0, -1]`, `SLAB_DC = [1, 0, -1, 0]`.
- A slab `i` is `slabs[i] = [a, b]` with `a <= b`. A placement `{ anchor, dir }` puts value `a` on `anchor` and `b` on the neighbour of `anchor` in `dir`.
- Player state `SlabsState = number[]` of length `2 * slabs.length`: `[anchor_0, dir_0, anchor_1, dir_1, ...]`, `anchor = -1` means in the tray (the dir is kept as the tray orientation).
- Rules: `SlabsRule = { kind: 'sum' | 'lt' | 'gt' | 'eq' | 'neq'; target: number }` (`target` is 0 and ignored for `eq`/`neq`). `regionOf[cell] = -1` means no rule.

### Task 1: Solver

**Files:** Create `packages/core/src/slabs/solver.ts`, test `packages/core/test/slabs.test.ts`.

**Interfaces (produces):**
- `SLAB_DR`, `SLAB_DC`, `type SlabsRuleKind`, `interface SlabsRule`, `interface SlabsPlacement { anchor: number; dir: number }`
- `interface SlabsPuzzle { config: { cols: number; rows: number }; blocked: Uint8Array; slabs: [number, number][]; regionOf: Int16Array; rules: SlabsRule[] }`
- `slabNeighbour(cols, rows, cell, dir): number` (-1 off board)
- `slabCells(p, anchor, dir): [number, number] | null` (null if off board or a blocked cell)
- `ruleHolds(rule, values: number[]): boolean` and `ruleBroken(rule, values: number[], open: number): boolean` (can no longer hold with `open` cells still empty, values 0..6)
- `solveSlabs(p, maxTier: 1 | 2 | 3): { solved: boolean; contradiction: boolean; steps: [number, number, number]; placements: (SlabsPlacement | null)[]; order: number[] }` (`order` = slab indices in the order they became fixed)
- `countSlabsSolutions(p, limit = 2, maxNodes = 2_000_000): { count: number; complete: boolean }`
- `slabsDifficultyReport(p & { slabs }): { score: number; steps: [number, number, number]; slabs: number; ruleless: number; weak: number }`
- `slabsCanonicalKey(p): string`, `slabsFamilyKey(p): string`

**Algorithm:**
- Placement list: every ordered pair of adjacent free cells `(c1, c2)` and every slab `s` gives `(s, c1, c2)` with value `a` on `c1`, `b` on `c2`; doubles only once per unordered pair.
- Tier 1 to fixpoint: kill placements whose values are not allowed in their cells or that touch a cell covered by a fixed slab; a slab with one placement is fixed; if every live placement covering cell `c` belongs to one slab, kill that slab's placements not covering `c`; if every live placement covering `c` also covers `n`, kill placements covering `n` that do not cover `c`; cell candidates = values of live covering placements intersected with `allowed`; rule bounds on `allowed` (sum/lt/gt min-max, eq intersection, neq removes fixed values). Contradiction: a slab with no placement, a free cell no placement covers, or an empty candidate set.
- Tier 2 (only when tier 1 is stuck): per region enumerate all value tuples over its candidates, keep supported values. One productive pass counts one tier-2 step.
- Tier 3 (only when tier 2 is stuck): for slabs ordered by fewest live placements, try each placement on a copy with tier 2; a contradiction kills it. One kill counts one tier-3 step.
- Solved when every slab is fixed and all rules hold.
- Exact counter: fill the first uncovered free cell with each unused slab in both value orders towards E or S, prune with `ruleBroken`.
- Canonical key: minimum over the rectangle-preserving symmetries of blocked mask, region ids renumbered in scan order, rules, plus the sorted slab list.
- Family key: counts of rule kinds and of ruleless cells.

- [ ] Step 1: write failing tests: geometry (`slabCells` rejects off-board, wrap and blocked); `ruleHolds`/`ruleBroken` for all five kinds; a hand-built 2×2 puzzle with two slabs and sum regions solves at tier 1 with the expected placements; a puzzle with a conflicting rule reports `contradiction`; `countSlabsSolutions` finds 2 on an ambiguous hand-built puzzle and 1 on the unique one.
- [ ] Step 2: run `pnpm --filter @puzzle-hustle/core test slabs`, expect failure.
- [ ] Step 3: implement `solver.ts`.
- [ ] Step 4: run tests, expect pass.
- [ ] Step 5: commit `Add Slabs solver`.

### Task 2: Generator

**Files:** Create `packages/core/src/slabs/puzzle.ts` (generator part), extend tests.

**Interfaces (produces):**
- `SLABS_VERSION = 1`
- `interface SlabsConfig { cols; rows; slabs; maxTier: 1 | 2 | 3; minTopSteps; minRegion; maxRegion; weaken: number }`
- `SLABS_PRESETS: Record<Difficulty, SlabsConfig>`: easy 4×5/6, medium 6×6/10, hard 7×7/14, genius 8×8/20
- `interface SlabsSpec extends SlabsPuzzle { version; seed; difficulty; config: SlabsConfig; solution: SlabsPlacement[]; order: number[] }`
- `generateSlabs(seed: number, difficulty: Difficulty): SlabsSpec` (throws after the attempt budget)

**Algorithm:** grow a connected tiling domino by domino inside the rectangle (bias toward frontier pairs with more neighbours in the area); draw slabs without replacement from the 28 of a double-six set, random orientation per domino; partition free cells into connected regions of `minRegion..maxRegion` cells; start every region with an exact sum; if tier `maxTier` cannot solve it, retry; then for each region in random order and with probability `weaken`, try weaker variants (ruleless, `lt`/`gt` with a random slack of 1 to 3, `eq`/`neq` where the values allow) and keep the first that still solves; require `steps[maxTier - 1] >= minTopSteps`; record the solver's fix order as `order`.

- [ ] Step 1: tests: same seed gives the same spec; every difficulty generates for 10 seeds, the solution satisfies all rules, `solveSlabs(spec, maxTier).solved`, `countSlabsSolutions(spec).count === 1`; the mean score rises easy < medium < hard < genius over 10 seeds; free cells equal `2 * slabs`; slabs are distinct.
- [ ] Step 2: run, expect failure.
- [ ] Step 3: implement.
- [ ] Step 4: run, tune presets until green and genius generates in under ~1.5 s per seed.
- [ ] Step 5: commit `Generate Slabs puzzles`.
